# Wikipedia Project

Bu repository, sadə bir **statik veb layihə**dir və HTML, CSS, şəkillər və audio fayllardan istifadə edilərək hazırlanmışdır. Layihənin məqsədi interaktiv və vizual olaraq zəngin bir səhifə yaratmaqdır.

## Canlı Demo

Layihənin işlək versiyasını buradan görə bilərsiniz:
[https://zarifawikipedia.netlify.app](https://zarifawikipedia.netlify.app)

## Layihə Strukturı

```
wikipedia/
├── index.html       # Əsas səhifə
├── style.css        # Saytın üslubu
├── image/           # Şəkil faylları
└── audio/           # Audio fayllar
```

## Texnologiyalar

* HTML5
* CSS3
* Audio və şəkil media faylları

## Necə İşlətmək Olar

1. Repository-ni klonlayın:

```bash
git clone https://github.com/zarifatb-15/wikipedia.git
```

2. Layihə qovluğuna keçin:

```bash
cd wikipedia
```

3. `index.html` faylını brauzerinizdə açın.

## Əlavə Qeydlər

Bu layihə **statik veb sayt** olaraq hazırlanıb və backend server tələb etmir. Saytı Netlify və ya digər hosting xidmətlərində yayımlaya bilərsiniz.
